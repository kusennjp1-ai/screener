# Q1 / F4 銘柄への直接リンクの初期表示

`7d9bde8` の90画面CIで、PCの3銘柄（MSM/ADI/TGTX）×両テーマのインライン撮影に `target-size` 違反があった。初回の `?symbol=` は選択だけを反映し、詳細位置へ移動しなかったため、チャートへスクロールした途中で概況の開閉ボタンが固定ヘッダーに半分隠れていた。

初回の対象銘柄のデータがそろった時点で、1回だけ詳細へフォーカスし、既存のヘッダー分の `scroll-margin-top` を使って先頭へ移動する。同一ページ内の通知クリックと同じ導線にそろえた。タブ切替・価格更新のたびにはスクロールしない。検査の対象要素やaxe基準は変更しない。

- 追加の単体テスト合格: 初回リンクの銘柄、詳細のフォーカス、スクロール位置指定、メモタブ操作後の再スクロールなし。
- ローカルPCで、詳細の上端56px、概況の下端56pxを実測。概況ボタンはヘッダーの背後に完全に移り、チャートと銘柄名が先頭に表示される。
- 両テーマ・3銘柄のaxe再計測は次のCIで記録する。修正しただけで合格とは扱わない。
