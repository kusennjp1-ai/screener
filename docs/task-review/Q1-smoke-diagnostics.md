# Q1 — 通常モードのスモーク検証と失敗証跡

## 確認した問題

通常CI [36878832486](https://github.com/kusennjp1-ai/screener/actions/runs/36878832486) の Frontend job（110425447137）では、lintとVitestは成功したが、スモーク6ケースが各画面の最初の要素待ちで失敗した。銘柄名・Pressure表示・ログイン見出しに到達していないため、チャート条件の不合格とは区別する。既存のジョブログにはブラウザー例外がなく、スモーク失敗のtraceも保存されていなかった。これだけでは根本原因を確定できない。

Windowsの通常モードViteをCUAで開くと、`/scan` と `/markets360/LLY` の画面は描画された。APIモックを持たないこの確認ではバックエンドへの500応答が発生したため、CIの6ケース全体の再現検証には代えない。

## 変更したもの

`1f1217e` は本体の起動処理・選定条件を変更していない。スモークの共通fixtureが `pageerror` と console error/warning を記録し、失敗時にジョブログと添付JSONへ保存する。通常CIにスモーク用の失敗成果物保存を加え、同じスモークテストを単独実行する Smoke Diagnostic workflow を追加した。

既存のアサーション、タイムアウト、リトライ数、APIモック、テスト件数は維持した。テストを合格させるための待機時間延長・条件削除・追加リトライは行っていない。

単独実行と通常CIの両方で失敗が再現しなかった。依存モジュールの事前処理や前段のVitestによる差などは仮説であり、原因として認定していない。通常CIの全Vitest後も同じスモークテストが成功したため、前段のVitestが原因だとも断定しない。

前回失敗の根本原因は未特定のまま記録する。今回は再現結果に基づく本体修正を加えていない。今後同じ失敗が再発した場合は、追加した例外JSONとtraceから原因を特定できる状態にした。

この記録はmainへの変更反映と検証の記録であり、公開サイトへのデプロイ完了を示すものではない。
