# F1 — 条件付き配分の未達・未確認条件

実装日：2026-10-01。配分・選定・購入の閾値、株数、金額、リスク計算は変更していない。

## 変更

- 配分を「日次条件をすべて通過」と「条件付き（未達・未確認あり）」に分離。
- 条件付きカードでは `readiness.rules` の未達・未確認名と根拠を全件常時表示する。カード内の条件名は折りたたまない。
- 通過数と分母は実際の条件配列を使用。7条件に固定せず、8条件のケースでも全条件が見えることを検証した。
- 目安価格を「条件成立時の目安」と表示。金額・想定損失を通過分と条件付き分に分け、合計は「全条件成立時の試算」と表示する。
- 条件詳細が欠ける、または旧通過フラグと根拠が食い違う場合は、未確認を明示する。
- 約520pxの右側ダイアログへ整理。名前付きの閉じるボタン、Esc、開いたボタンへのフォーカス復帰を実装。
- `PortfolioDecision` の `compact` / `plan` / `prepared` / `renderTrigger` でホームのヒーローから再利用できる。
- 軽量データに形状の説明文がない場合、形状の真偽に応じた説明を表示する。判定の値は変更していない。
