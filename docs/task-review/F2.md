# F2 — あと1条件の監視候補

実装日: 2026-10-01。

候補ボードの操作バー、または「候補を絞り込む」の「あと1条件」で、手法サマリーの `passed === total - 1` の銘柄だけを表示する。「全条件通過のみ」とは排他的に切り替わる。リストと比較カードに、正準ルールを読み直した不足条件を1つ表示し、**未達 / 未確認**を区別する。いずれも合格・購入可には変更しない。

CSVの末尾に `missing_condition` を追加。短縮表示した画面ラベルと異なり、CSVには元の条件名と「未達 / 未確認」を保存する。複数条件不足・全条件通過では空欄。検索・ウォッチ・流動性・業種・日足検証の絞り込みを維持する。個別再検証などでサマリーと現在の根拠が一致しない場合は、条件を作らず「判定資料を再確認」と表示する。

## 検証

- 4手法の件数がサマリーの定義と一致する単体テスト（不足が1件の未達、1件の未確認、2件以上、全通過）。
- 欠損の未確認を合格にしないこと、CSVの状態付き条件名、検索・流動性・ウォッチの維持を確認。
- 実際の絞り込みDrawerで、全条件通過とあと1条件が排他的に切り替わり、未達・未確認のラベルが出るUIテストに合格。
- 対象のルール・表示・比較カード・UIテスト31件に合格。
- `npm run lint`: エラー0、既存警告8。

Q1/Q2の実データブラウザ検証に、リストと比較の「あと1条件」モードの4条件撮影を追加した。スクリーンショットと採点、全体 `npm run test:run` の結果は統合検証で追記する。未実施の撮影・採点を合格とは扱わない。
