# D3 implementation and acceptance

Candidate list uses 51px desktop / 70px mobile rows, company truncation, price-position meters, distance/RS/volume columns, incomplete-only count badges and row selection. Column sorts and select share state; up/down move and Enter expands. 50-row pagination preserves the full search/sort universe.

Status: implemented, integrated acceptance pending. Required lint/full test suite and desktop/mobile dark/light screenshots, four subjective scores and objective gates will be recorded in docs/design-review. No unmeasured result is counted as a pass.
