# S1 — 詳細スキャンの空列・日本語表示・モバイル件数

## 実装
- RS推移・株価推移の有効な配列が表示ページに一つもなければ、見出しとセルを一緒に非表示にする。配信済みの場合は既存の配列を描画し、追加の通信はしない。
- 見出しの幅を表示文字数に応じて確保。並べ替えと説明ボタンの幅も確保し、元のソートキーは維持した。
- 指標・パターン・プリセット・ページ送り・フィルターの文言を日本語化。業種はホームの同じ分類定義を使用。細分類は配信されているIBD分類名に対応する表示専用の翻訳辞書を追加した。分類のキー・検索条件・順位計算は変更していない。
- 0件の補助プリセットを無効化し「該当なし」と説明。件数が未取得のプリセットは0件として無効化しない。
- スマホは1ページ20件。読み込み途中も20件までとし、1行に銘柄・社名・株価、その下に4指標を簡潔に表示。元の全体件数・並べ替え・ページ送りを維持し、不明な準備条件を「未確認」と表示する。
- タイトルは「詳細スキャン」。リセット・表示切替・並べ替えのボタンは折り返さず、タッチ操作を44pxに揃えた。
- 根拠不足の真偽値は空欄相当として区別し、未確認を未達・通過へ変換しない。
