# D7 — 6銘柄の比較ビュー

実装日：2026-10-01。選定・並び順・購入条件は変更していない。

- 1280px以上は3列×2行、768〜1279pxは2列、スマホは1列。チャートはPC220px、スマホ240px。
- 見出しを銘柄・価格位置・ピボット比、次行を社名・価格、下端を買い上限・損切り例・RS/出来高・購入条件に整理。
- カード全体で分析を開く。読み上げには価格位置、共通ピボット、未達件数、日付も含める。
- 画面外・読み込み待ちは静止スケルトンとし、虚構の値動きは描かない。欠損・日付不一致は明示する。
- 買いゾーンと損切り例の破線を描き、価格軸に含める。値は `entryPlan` の `pivot` / `upper` / `stopExample` そのものを使用する。ミネルヴィニ第2方式の+3%も、+5%へ置き換えない。
- ピボット・上限・損切り例のラベルは価格軸側で衝突を避ける。ローソク足上のタイトルは描かない。
- 出来高は通常を中立色、直前50日平均の1.4倍以上を強調色にする。50日未満は強調判定せず中立色のまま。

## 検証

- 対象テスト4ファイル：**13件通過・0失敗**。最大6件、全カード共通期間、+3%の共通水準、損切り例の縦軸への包含、日足欠損・不整合の表示を確認。
- `npm run lint`：**0エラー・既存警告8**。
- 比較グリッド≤700px、1440×900で6枚、スマホで1.5枚以上という実測ゲート、両テーマのaxe・撮影・採点は統合検証で記録する。CSS寸法の机上計算だけで合格とはしない。
