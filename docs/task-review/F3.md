# F3 — 公開済み候補の5・20・60営業日後の成績

実装日：2026-10-01。

## 計算と保存

- 公開サイトから復元する候補履歴の通過状態だけを標本にする。現在の選定結果から過去の通過銘柄を作らない。
- 初回保存を維持し、保存期間を30→126営業日に延長。60営業日後を観測する前に元の候補を捨てない。
- 各分析日・方式・5/20/60営業日ごとに、終値騰落率、同じ期間のSPY騰落率、期間中の終値高値からの最大下落率を計算。
- NYSEカレンダーで観測日を数える。途中の日足が欠けていても営業日を詰めて代用せず、未検証銘柄やSPY欠損は除外件数とともに明示する。
- 対象銘柄は公開時のものを固定し、終値系列は現在の公開済み日足を独立再検証する。分割等の大きな不連続を検出した系列は使わない。配当込みの総合リターンや実売買成績ではない。
- 手法別に中央値・上昇割合・標本n・観測営業日数を表示。標本nは「銘柄×分析日」で、同じ銘柄の別日観測も含む。n<20は参考値（標本不足）。未観測の騰落率はnullのままにし、0%を作らない。
- 成績はハッシュ付きの別ファイル。ユーザーが「過去の通過銘柄を検証する」を開いてから読む。初期一覧の転送量には加えない。

- 固定データの対象テスト2ファイル：**20件通過、0失敗**。
- 5・20・60の正確な終点、米国の祝日を挟む5営業日、最大下落率、調整後系列、途中欠損、SPY欠損、未来の候補除外、公開履歴がない場合の空欄を検証。
- `npm run lint`：**0エラー、既存警告8**。
- 全体テストと画面の4条件撮影・axe・採点は統合検証で実施・記録する。実データで5営業日の結果がまだ存在しないことは完了した実績値として扱わない。次の日次公開以降、保存した初回候補から自動で観測を進める。

## 限界

価格の修正・分割調整は現在配信している日足の品質検証に依存する。上場廃止などで終値を取得できない銘柄は現在の生存銘柄へ置き換えず、欠損として元の対象数に残す。成績の全分析日集計には公開当時のルール版の改定を含み、分析日ごとの表示で元の標本を追える。

## 公開前の独立再確認

- 旧エクスポートのSPY日付から営業日を代用する経路を除去。SPY欠損日を営業日カレンダーから落とすと「5営業日後」がずれるため、NYSE営業日の明示配列がないデータは未検証とする。`export-sector-prices.py` による次回更新で配列を取得するまで空欄を維持する。
- 公開済み候補の記録は日時・ハッシュを検証し、未来の記録を除く。現時点で上場していない/検証できない銘柄は分母から消さず、欠損・未検証数へ残る。
- 終値は現在の分割調整済み履歴で再計測するため、当時の価格配信そのものの再現ではない。分割などの不連続を検出した系列はリターンを出さない。欠損が多い場合、取得できた標本だけの中央値に偏りが生じ得るため、対象数と欠損数を併記する。

## 確定済み観測の固定保存（2026-10-01追補）

後日の上場廃止や現在の日足の欠損によって、過去に検証できた成績まで空欄へ戻る経路を修正した。以下は実装・対象テストまでで、コミットと公開は統合担当が行う。

- `candidate-performance-history/index.json` と銘柄×5/20/60営業日の観測を含むcohort別のハッシュ付きgzipファイルを公開成果物へ出力する。公開済みcohortのSHA-256、分析日、ルール版、対象範囲版が完全一致するものだけ再利用する。
- 5/20/60営業日が実際に経過し、途中の株価・SPY・NYSE営業日が揃い、取得日時が公式カレンダーの当日終了時刻以降かつ現在時刻以前である観測だけを固定する。未成熟・未確認・欠損から確定結果を作らない。
- 株価とSPYの対象区間終値、NYSE営業日、分割調整方式、元チャートのバイトハッシュ、ベンチマークの正規化JSONハッシュとその定義、取得元、取得日時、確認日時を保存する。復元後も元の区間を再計算して保存結果と一致することを検査する。
- 同じcohortの確定観測は最初のものを維持し、後日の価格修正・別のcohort・違うルール版・未来の観測で置き換えない。公開サイトから過去cohortと確定観測の両方を復元する。
- 保存済み確定観測のファイルは、現在の126営業日の候補一覧から外れた後も観測カタログに残す。画面の分析日一覧は既存の候補履歴保持範囲に従う。確定前に欠損となった銘柄の成績は依然として未検証であり、総合リターンや実売買成績ではない。
