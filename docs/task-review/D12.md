# D12 restrained motion and numeric notation

Only the hero entrance and entry-zone reveal animate once (180–300ms). There are no repeating decorative timers. prefers-reduced-motion disables every transition/animation, including portal components. Core price/percent/ratio formatting uses grouped two-decimal USD prices, Unicode minus, ± for zero and × for volume ratios. Display rounding does not replace exact source values or comparisons.
