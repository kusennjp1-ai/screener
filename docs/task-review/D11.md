# D11 — 業種ローテーション

- reference/geometry.js の対称座標軸、円の半径、ラベル衝突回避を React に移植。表示期間に対応する配信済みの相対指数、21日指数、ミネルヴィニ通過率を使い、指標や選定条件を変更していない。
- 横軸は63/126営業日の相対指数、縦軸は21日の相対変化。円の大きさは常にミネルヴィニ通過率で、選定方式の切替により円の意味を変えない。
- 4象限を日本語で表示し、簡易版でJdK RS-Ratio / RS-Momentumとは異なると明記。価格が欠ける業種を図から除外し、件数を明記して一覧には未確認として残す。通過率が欠ける場合は欠損を維持し、ゼロと断定しない。
- 一覧のホバー・キーボードフォーカスと図を連動。図のラベルは衝突時に省略し、全業種名と数値を一覧で引き続き確認できる。図には4象限の銘柄名と未確認数を含む日本語の代替説明を設定。
- PCでは見出しと図を左右に配置。スマホでは図を一覧の後に置き、読み方を閉じて初期ページ高を抑える。色は共通のセマンティックトークン、操作目的のないアニメーションは追加していない。
