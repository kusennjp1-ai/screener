# D1 — shared semantic design tokens

Colors, typography and MUI theme now come from static/theme/tokens.js; CSS variables cover both light and dark themes. The supplied design-target palette is used with Zen Kaku Gothic New and Geist Mono (display=swap). Existing static research/market/legacy cards use semantic variables; drawing colors are migrated with D6.

Validation status: implementation in progress. Full lint/test, hardcoded-color audit, four viewport/theme captures and visual/axe score are required before acceptance. This commit does not claim those unmeasured gates passed. Objective results will be recorded in docs/design-review after integration.
