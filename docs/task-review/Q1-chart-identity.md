# Q1 — チャートの銘柄・基準日を必ず照合

独立照合で、インラインチャートが配信ファイルの銘柄・日付を照合せず描画する経路を発見した。拡大チャートも独立した基準日がない場合は日付検証を省いていた。

- 共通の `requireChartIdentity` が、選択された銘柄・分析日と、ファイルのsymbol/as_of_date/最終日足日を照合する。基準日の欠損、別銘柄、別基準日、末尾の古い日足、配列の欠損は描画を拒否する。
- Queryのselectで検証するため、ネットワーク再取得がない既存キャッシュにも同じ検査を適用する。エラー時は以前のローソク足を表示せず、再取得導線を保つ。
- 拡大詳細の併合では、インラインと同じく現在の一覧の共通ピボット・価格・品質・再計算状態を優先する。同日詳細の別値が一覧を上書きしない。
- 選定閾値・ピボット検出・配分計算は変更していない。
