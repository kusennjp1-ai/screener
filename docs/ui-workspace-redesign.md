# リサーチワークスペースのUI設計

2026-10-25。ユーザーの「美しいグラフィック、一目でわかる情報、チャートでVCP条件を確認、市場環境を理解できるUI」を実装する。

## 情報構成

- 左側に常設するワークスペースナビゲーションで、候補選定・チャート比較・市場環境を行き来する。
- 候補画面は手法と絞り込み、当日の概況、候補と詳細という順序。選定・買い位置・日次購入条件は別の情報として表示する。
- 候補カードは実際のRS、出来高、前日比、価格位置、日足ミニチャート、条件状態を保持し、色だけで意味を伝えない。
- チャートと市場環境はそれぞれの根拠データに結び付け、未取得や未確認の情報を成功表示しない。
- 1200px以上は224pxの左サイドバー、701–1199pxは76pxのコンパクトナビ、700px以下は下部ナビと一覧→詳細の導線。

## 視覚設計

Slackのワークスペース構成と、TradingViewの表・チャートの切り替えを参考にする。ロゴやブランド素材の複製は行わず、LEADERの分析用UIとして再構成する。

- [Slack公式ガイド](https://slack.com/help/articles/360059928654-How-to-use-Slack--your-quick-start-guide/)
- [TradingView Chart view mode](https://www.tradingview.com/support/solutions/43000724233-chart-view-mode/)

濃いインディゴのナビ、白/ネイビーの分析面、控えめな紫の選択色、緑・赤・黄の状態色を使用する。全色は既存の`theme/tokens.js`へ集約する。角丸のカード、余白、罫線と数値の揃えで情報のまとまりを表現する。外部フォントや画像の取得を必須にしない。

`workspace.css`は既存の`leaderFeed.css`より後で読み込み、`.workspace-shell`に限定して新しいレイアウトを適用する。スクリーニングの判定式・価格データ・財務の期限は変更しない。測定契約の版更新に伴う履歴読込互換性は、ライブ測定と分離して実装する。

## 検証

- 360/390/768/1440pxで横はみ出し、ラベルの欠け、チャート幅、固定ヘッダーと下部ナビの重なりを確認する。
- ダーク/ライト、キーボードフォーカス、縮小モーション、ルート切り替え、検索とフィルターを確認する。
- 候補カードは全ティッカー、データなし、未達/未確認/対象外、CSVと一覧の一致という既存契約を維持する。
- 新しいワークスペースのRadar測定は`workspace-hero-fixed-slot-visible-v4`と明示し、実際のCSSと祖先クラスを使用する。既存の時間・可視性閾値を変更しない。
- 保存済みの認証済み画像パッケージだけは、専用の履歴読込経路で既知のv3/v4契約を検証する。v3は旧クラスと旧フォント条件を固定して読み、新しい測定を通すためには利用しない。未知の版や版とクラスの混在は拒否する。
- 過去のX型フィード画像を新しいワークスペースの視覚検証として使わない。公開前に変更後の実画面を確認する。

最終の実行結果・画面確認はPRに記載する。この設計書自体はテスト成功や公開完了の証明ではない。

## 実装済みの画面と操作

### チャートのVCP確認

`ChartSetupEvidence`を通常・拡大チャートに追加した。既存のチャート注釈と同じ検出結果から、収縮回数、最終区間の値幅、C1と比較した区間平均出来高を表示する。C1/C2等の区間を選ぶと、チャートが該当区間に移動する。開始/終了日、高値/安値、平均出来高を確認でき、図上ガイドの表示も切り替えられる。

表示は「自動検出の参考図解」。ベース候補のみ、収縮未確認、整合性未確認、週足表示時を区別する。日次購入条件やVCP成立を独自に合格へ変換しない。区間平均出来高の減少と、最終日の出来高枯渇は別であると画面内に明記する。

### 市場環境

`MarketPulse`の市場概況と推移を隣接させ、10営業日レシオ、基準1.00、直近1日の上昇/下落銘柄数を分けて表示する。1か月/3か月を切り替えられ、欠損区間を線で接続しない。

`MarketContextCards`は「指数の方向」「高値・安値の更新」「先導株の状態」の3視点を表示する。既存の市場根拠の版・分析日・観測完了を確認し、未確認の値を数値で補わない。観測母集団は公開チャート集合であり、市場全体の統計とは区別する。

### レスポンシブと操作性の修正

- タブレットではJSとCSSの切り替え境界を700pxに揃え、701–800pxで詳細が非表示になる旧CSSとの衝突を解消した。レーダーはタブレットで全幅に配置する。
- モバイルのヘッダー高さに合わせてスクロール予約領域を調整し、絞り込み確定後の候補一覧フォーカスがヘッダーに隠れないようにした。
- 拡大チャートの購入条件サマリーに余白を追加し、375px画面での上端の重なりを解消した。
- デスクトップの固定見出しは観測日と同じ行に配置し、既存の表示契約を保持した。市場概況カードの説明文はカード内で折り返す。
