# OBJECTIVE — 目的関数（ユーザーとの約束）

このスクリーナーを「最高の聖杯」に育てるための**判断基準の優先順位**。
毎サイクルで「良くなったか？」を判定するときは、必ずこの順で見る。
上位が同点/悪化なしのときだけ、下位の改善を採用する（**上位を犠牲にした下位改善は不採用**）。

## 優先順位（不変・ユーザー合意 2026-07-23）

1. **CAGR（年率幾何平均成長率）** — 最終的に資産がどれだけ増えるか。複利の源泉。
2. **最大ドローダウン（Max Drawdown）** — 生き残り。深い谷は複利を壊し、退場リスクを生む。
3. **リスク調整後リターン** — **Sortino を主・Sharpe を従**とする。
   理由: Sharpe は上振れ（大勝ち）も「ブレ＝リスク」として罰する。我々は右テール（大勝ち）を
   **残す**戦略なので、上振れを罰する指標で自分を採点してはいけない。Sortino は**下振れだけ**を
   罰するので、この戦略の思想と一致する。両方記録し、判断は Sortino を優先。
4. **期待値（1トレードあたり／R倍）** — 1回の賭けが平均でプラスか。`expectancy_r`・`payoff_ratio`。
5. **勝率** — 最下位。ミネルヴィニ自身が「勝率は最も重要でない」と言う。
   低勝率でも payoff_ratio が高ければ +EV。勝率を上げるために大勝ちを早取りするのは**本末転倒**。

## この順位から導かれる不変ルール

- **右テール（大勝ち）を機械的に切らない**。利確固定・利益上限は入れない。

  **根拠を差し替えた（C103）**。ここには以前「C71/76/80/82/85 の5連続棄却が実測」と
  書いてあったが、**この5件のうち勝ち玉を切る実験は1つも無い**（C76 はバックテストではなく
  908ハーネスで棄却された検出系の実験、C80 は**採用**されている＝バグ入りの初版だけが失敗）。
  不変ルールの根拠が、それを検証していない実験を指していた。

  実際に勝ち玉を切る実験は C67（全部利確）と C68（半分利確）だけで、当時は**9年窓で改善**
  していた。そこで上場時期バイアスを除いたハーネス（`--pit-universe --quality-rank`）で
  **両窓とも測り直した**（C103・事前に予測を書いてから実行）:

  | 変種 | 窓 | CAGR | 最大DD | Sortino |
  |---|---|---|---|---|
  | ベースライン | 5年 / 9年 | 10.7 / **11.5** | −15.8 / −18.4 | 1.03 / 1.07 |
  | 強さへ全部利確 | 5年 / 9年 | 12.1 / **9.1** | −18.1 / −21.7 | 1.33 / 0.97 |
  | 半分利確 | 5年 / 9年 | 9.4 / **7.8** | −17.8 / −17.9 | 1.05 / 0.85 |

  **両変種とも棄却**。全部利確は9年窓でCAGRが2.4pp落ち最大DDは両窓で悪化、半分利確は
  両窓でCAGRが落ちる。5年窓だけ見れば全部利確は「CAGR +1.4pp・Sortino 1.03→1.33」で
  魅力的に見えるので、**片窓判定は必ず誤る**。

  **指標の罠（記録）**: 半分利確の期待値は 1.72R・勝率61.5% と極めて良く見えるが CAGR は
  9.4%に悪化している。分割決済のたびに別のトレード記録が書かれてトレード数が158→340に
  膨らむため。**期待値と勝率はこの変種間で比較してはならない**。
- **検出の再現率は、リターンの代理指標ではない**（C103・実測で否定）。

  このプロジェクトは C69/C70/C75 と、908トレード正解データに対する**再現率を上げること**を
  改善の梃子として扱ってきた。C102 のベース固定型検出は、その基準で明確に改善した
  （再現率 36.1→40.3%、対照率 16.0→12.8%、lift 2.26→**3.14** ＝ 再現率と精度が同時に向上）。

  それをバックテストの売買経路に入れて両窓で測ったところ、**両窓とも悪化した**:

  | | 5年 | 9年 |
  |---|---|---|
  | CAGR | 10.7 → **8.0** | 11.5 → **8.2** |
  | 最大DD | −15.8 → **−20.9** | −18.4 → **−21.8** |
  | Sortino | 1.03 → 0.79 | 1.07 → 0.80 |
  | トレード数 | 158 → 170 | 292 → 338 |

  増えたトレード（+12 / +46）が損を出した。**908の再現率が測っているのは「ミネルヴィニが
  買った日に反応するか」であって、「このハーネスの売買ルール（翌日始値・8%ストップ・
  50日線割れ）でそれが利益になるか」ではない。**

  同じことを別の角度から示す実測が既にある: 約定レーン別に見ると、**ピボットに最も近い
  レーン（armed）は両窓とも損失**（−0.18R / −0.06R）で、利益はすべて +2.6% 上で追いかけた
  レーンから出ている。良い設定を早く見つけることと、この執行で儲かることは別問題。

  **∴ 検出器の改善は「表示と並び順の正しさ」として採用してよいが、リターン改善の根拠には
  ならない。売買経路に入れる場合は必ず両窓のバックテストで別途証明すること。**

- **左テール（損失）は小さく**。損切りは約8%（`MAX_LOSS_PCT=0.08`）＋トレイリング。
- **勝率を目的にしない**。勝率は結果であって目標ではない。
- 数値フィッティング禁止。metric の追加・変更で見かけの改善を作らない。
- 凍結metric（FIRE±5 / GATE / golden / Band right-edge）の低下＝即revert。これは上の1〜5とは
  別の「品質の床」＝候補選定の正しさを守るガードレールで、常に維持する。

## 実測値（★C98訂正版・両窓とも`--pit-universe`＝上場時期バイアス除去後）

**旧記載（6年 CAGR+15.2%＝5指標すべてSPY超）は撤回。** 対象銘柄が検証開始時点で固定される欠陥により**過大**だった（下記「C98訂正」参照）。正しい条件で測り直すと**両窓とも同じ姿**になる：

| 優先 | 指標 | 5年窓(run 30167396207) | 9年窓(run 30135665125) | S&P500 B&H (5年/9年) |
|---|---|---|---|---|
| 1 | CAGR | **+10.4%** | **+11.0%** | +12.4% / +14.8% |
| 2 | 最大DD | **-15.8%** | **-18.6%** | -24.5% / -33.7% |
| 3 | Sortino | **0.94** | **0.93** | 1.06 / 1.01 |
| 4 | 期待値 / payoff比 | **+0.38R / 3.01** | **+0.38R / 2.65** | — |
| 5 | 勝率 | 35.8% | 39.1% | — |

- **一貫した結論**: **①CAGRは指数にやや届かない**（10-11% vs 12-15%）が、**②最大DDは指数の6〜7割**、**③Sortinoはほぼ互角**（0.93-0.94 vs 1.0-1.06）。窓を変えても同じ＝**これが本戦略の素の実力**。
- **市場ゲートが最大の武器（両窓で再確認）**: ゲート無しは5年 CAGR**1.2%**/DD**-35.8%**、9年 CAGR4.7%/DD-31.8%。∴ゲートだけで**5年+9.2pp・9年+6.3pp**のCAGRと**20pp/13pp**のDD改善。
- **旧6年値（参考・バイアス込み）**: CAGR+15.2%・DD-13.9%・Sortino1.28。**看板に使わない**。

- **右テールの実測**: 上位10%の勝ちが総利益の**68.4%**、最大1件で14.2%、最大勝ち**+12.23R**、≥5Rが9件。
  中央値は**-0.63R**（大半のトレードは小さな負け）＝「負けは小さく、少数の大勝ちが全体を担う」を数字で確認。
- **市場ゲートの効き**: 同じ検出でも市場ゲート無しだとCAGR+4.8%・最大DD-32.1%に劣化＝エクスポージャー調整が主要レバー。
- **窓依存の正直な注記**: この6年窓は2022ベアを含むため防御が効いてB&Hに勝つ。純粋な強気5年窓ではB&Hに勝てない（型自体は両窓で実証・凍結外の参考値）。

### さらに広げた9年窓（2017-08〜2026-07・ほぼ上げ相場・run 30064735759）＝正直な弱点

| 優先 | 指標 | 本戦略 | S&P500 B&H |
|---|---|---|---|
| 1 | CAGR | **+4.3%** | **+14.7%** |
| 2 | 最大DD | -25.8% | -33.7% |
| 3 | Sortino | 0.46 | 1.01 |
| 4 | 期待値 | +0.14R（payoff2.32・右テールtop10%=72.3%） | — |
| 5 | 勝率 | 34.8% | — |

- **結論（測定値として）**: 2017年からのほぼ上げ相場9年では、**ただS&P500を持ち続ける方が圧倒的に強い**（+243% vs +45%）。**下げ耐性は優位**（最大DDは浅い・2022年 -3.6% vs -18.2%）。右テール構造と期待値プラスは9年でも維持＝手法自体は健全。
- **含意**: この戦略の「聖杯」は上げ相場でB&Hに勝つことではなく、**下げ相場での資本保全＋安定した期待値で長期に生き残る**こと。窓依存を隠さずスコアカードに両窓を表示。

#### C98訂正: 上記9年の「敗因」説明は誤り＋数値自体に下方バイアス

**(a) 「現金を持つ機会損失」という説明は誤り。** 年別を見ると強気年に**マイナス**になっている: 2019 **-4.9%**(SPY+31.2)・2021 **-3.7%**(SPY+28.7)・2025 **-7.7%**(SPY+17.7)。平均投資64.9%なら+31%の年は+20%前後になるはずで、**マイナスは機会損失では説明できない**。実態は**ブレイクアウトの失敗を繰り返す往復ビンタ**（9年287トレード中、**126件=44%がフルストップ**`<=-1R`）。6年窓でも同年は+1.8%/+2.7%とSPYに大差で劣後＝**窓を変えても消えない構造的弱点**。これが本当の改善対象（＝CAGRを削っている主因）。

**(b) 9年の数字自体が下方バイアス（ハーネス欠陥・C98で修正）。** 対象銘柄リストが**検証開始バーで固定**され、以後上場した銘柄は全期間不可視だった（`tradable`を1回だけ構築）。∴9年窓は**2017年時点の上場銘柄しか買えない**＝本手法が最も狙う「新しい成長リーダー（近年IPO）」が丸ごと除外。`--pit-universe`（日々の適格判定＝実際のスクリーナーと同じ）を追加し、既定はオフ（既存数値の再現性維持）。

### ★C98 再測定＝バイアス除去後の9年窓（run 30135665125・同期間・同戦略）

**除外されていた銘柄は708件＝適格銘柄の37%**（1232 → 1940）。除去すると数字が一変した：

| 優先 | 指標 | 旧（固定リスト） | **新（日々更新）** | S&P500 B&H |
|---|---|---|---|---|
| 1 | CAGR | +4.3% | **+11.0%** | +14.8% |
| 2 | 最大DD | -25.8% | **-18.6%** | -33.7% |
| 3 | Sortino | 0.46 | **0.93** | 1.01 |
| 4 | 期待値 | +0.14R | **+0.38R**（payoff2.65） | — |
| 5 | 勝率 | 34.8% | **39.1%** | — |
| — | 総リターン | +45.4% | **+155.2%** | +243.6% |

- **年別も一変**: 2018 -9.7%→**+14.8%**（SPY-4.6%）・2019 -4.9%→-0.9%・2021 -3.7%→+0.9%・2025 -7.7%→-0.1%。
  ∴**(a)の「強気年にマイナス＝往復ビンタ」も大半がこのバイアス由来**だった（古い銘柄だけで無理に売買させられていた）。強気年の劣後（+0.9% vs +28.7%等）は残るが、**「負ける」ではなく「乗り切れない」**に修正される。

- **市場ゲートの価値が再確認**: 同条件で市場ゲート無し＝CAGR4.7%・最大DD-31.8%。**ゲートだけでCAGR+6.3pp・DD13pp改善**＝エクスポージャー規律が最大のレバーであることが9年でも成立。
- **教訓（恒久）**: 「戦略が悪い」と結論する前に**計測系を疑う**。今回は結論の約6割が計測アーティファクトだった。


### ★C100 採用決定: 品質順スロット配分（`--quality-rank`）

**両窓で①CAGR改善・②最大DD悪化なし**を確認したため採用（判定基準どおり）。過去の棄却は歪んだ物差し（上場時期バイアス）での測定だったため、正しい物差しで再測定した結果の反転。

| 優先 | 指標 | 5年: 現行→採用 | 9年: 現行→採用 |
|---|---|---|---|
| 1 | CAGR | 10.4% → **10.7%** | 11.0% → **11.5%** |
| 2 | 最大DD | -15.8% → -15.8%（同） | -18.6% → **-18.4%** |
| 4 | 期待値 | 0.38R → **0.40R** | 0.38R → 0.38R（同） |
| 5 | 勝率 | 35.8% → 36.1% | 39.1% → 38.7%（微減・最下位指標） |

- **理論的根拠**: ミネルヴィニ「最良の設定を買う」。限られた10枠を**RSだけ**で埋めるのではなく、**検出済みVCPベースを優先**し同順位内でRS降順。数値スイープではなく既存の順序規則の採用。
- **注意（Sortino比較不可）**: 9年の採用側run(497cbd9)はSortino式修正後、現行側run(30135665125)は修正前。式が違うため③は同一式で再測定するまで比較しない。
- **製品反映**: スマホの「バックテスト準拠候補」の並びをVCP優先→RS降順に変更（採用構成と一致）。バックエンドの`quality_rank`ソートは既存（`_QUALITY_SOURCE_TIER`）。
