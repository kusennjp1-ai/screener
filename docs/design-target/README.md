## 2. コンセプト「Ink Instrument（インクの計器）」

- **判断を最初に、根拠をその下に。** 最初の1行は結論（「候補あり。」）、次の1行は次の行動（「発注前に、未達の条件を確かめる。」）。数字と図はその根拠として下に置く。
- **色は意味だけに使う。** 状態色は5つ（ゾーン内・待ち・超過・損切り/下落・対象外）。`accent`（紫）は「選択中」と「操作できるもの」だけに使う。装飾のための色は使わない。
- **一点だけ光らせる。** 画面の中で光ってよいのは「買いゾーン（ピボット〜+5%）」だけ。レーダー、ゾーンメーター、位置ゲージ、チャート、比較カードのすべてで、同じ緑の帯が同じ意味を持つ。
- **計器のような精度。** 数値はすべて等幅（Geist Mono、`tabular-nums`）。符号はマイナス記号「−」（U+2212）、0は「±」。軸ラベルは図の外ではなく、データの近くに直接書く。

- 影は使わない。区切りは枠線と面の明度差だけで作る。

### 3.2 文字
- 和文 UI：`"Zen Kaku Gothic New"`（400 / 500 / 700 / 900）、`font-feature-settings: "palt"`。
- 数値・銘柄記号・日付：`"Geist Mono"`（400 / 500 / 600）、`font-variant-numeric: tabular-nums`、`letter-spacing: -0.01em`。
- 読み込み：Google Fonts（`display=swap`）。日本語はサブセット化されたものを使う。
- **段階（9段階のみ）**：

  | px | 用途 |
  |---|---|
  | 42 | 本日の判断のH1（PCのみ、1画面1回） |
  | 34 | 各ページのH1、銘柄記号、株価、スマホのH1 |
  | 26 | ヒーローのKPI数値 |
  | 20 | サブ見出し（「発注前に…」「改善中は…」）、カードの銘柄記号 |
  | 16 | 強調した数値（ピボット比）、スマホのサブ見出し |
  | 14 | 本文・ボタン |
  | 13 | 表の数値・補足 |
  | 12 | ラベル・凡例 |
  | 11 | 軸・チャート内のタグ（最小） |

### 3.3 余白・角丸
- 余白は4pxの格子（4 / 8 / 12 / 16 / 24 / 32）。カードの内側はPC 20〜22px、スマホ16px。
- 角丸は **4**（チャート内のタグ・小さな帯）、**8**（ボタン・セグメントの項目・フォーカスリング）、**12**（セグメントの外枠・入力欄・アイコンボタン）、**16**（カード・引き出しパネル）、**ピル**（状態チップ）の4種類＋ピル。

### 3.4 動き
| 名前 | 内容 | 使う場所 |
|---|---|---|
| `rise` | 0.6s、下から8px・不透明度0→1、`cubic-bezier(.2,.8,.2,1)` | カード・行の登場（40〜60msずつずらす） |
| `pop` | 0.55s、縮小→等倍 | レーダー・ローテーション図の点（1点あたり4〜40msずらす） |
| `draw` | 1.2s、線を描く（`pathLength=1` と `stroke-dashoffset`） | 移動平均線 |
| `sweep` → `breathe` | 帯が下から伸び（0.9s）、その後3.2sで明滅 | 買いゾーン帯（レーダー・チャート） |
| `slide` | 0.32s、右から24px | 引き出しパネル |
| ホバー | 背景・枠・文字色を0.16sで変える | 行・ボタン・ナビ |

- 動くのは「登場」と「買いゾーン」だけ。データの値を動きで誇張しない。
- `prefers-reduced-motion: reduce` ではすべて止め、線は描き終わった状態で表示する。

## 5. 部品（座標計算は `reference/geometry.js`）

### 5.1 セットアップ・レーダー（`radar()`）
- 横：ピボット比。**区分線形**：−15〜+10%を幅の84%、+10〜+25%を残り16%に圧縮し、+10%の位置に「//」の省略記号。範囲外は端に寄せる。
- 縦：RS 70〜100。円の半径＝`2.4 + min(出来高比, 3) × 1.4`。
- 色＝状態（ゾーン内 不透明度0.95、それ以外0.6）。描く順は 超過→待ち→ゾーン内（ゾーン内を最前面に）。
- 買いゾーン（0〜+5%）は縦の帯＋破線の縁＋上端に「買いゾーン 0〜+5%」のラベル（背景は `--ground`）。
- 選択中の銘柄：`accent` の輪、十字の点線、横にラベル（銘柄・状態・ピボット比・RS）。右端28%に入る点はラベルを左に出す。
- ホバーでラベルを出す。詳細データがない点は「詳細なし」と添え、押しても何もしない。
- SVGの `<text>` は使わず、軸やラベルはSVGの上に重ねたHTMLで、位置は%で指定する（拡大縮小で文字がつぶれないように）。
- 読み上げ：`role="img"` と要約の `aria-label`（「ミネルヴィニ通過207銘柄…買いゾーン内は48銘柄」）。

### 5.2 候補ボードの行とゾーンメーター（`meter()`）
- 行（PC 51px、`button`）：銘柄（等幅・選択中は `accent`）＋社名（省略）｜ゾーンメーター112px ｜ ピボット比 ｜ RS ｜ 出来高比（1.4倍以上は `--zone`）。
- ゾーンメーター：−10〜+10%の線、0〜+5%の帯、0%に縦線（ピボット）、現在位置の点（状態色、範囲外は端）。行ごとの状態の文字は出さず、ボードの上に凡例「帯＝買いゾーン · 線＝ピボット」を1回だけ出す。
- 列見出しは並べ替えボタン（`aria-pressed`）：銘柄＝選定順、位置 / ピボット比＝ピボットに近い順、RS＝高い順、出来高＝高い順。
- `aria-label` に要約（「MSM、MSC Industrial…、買いゾーン内、ピボット比 +0.0%、RS 84、出来高 1.27×」）、選択中は `aria-current="true"`。

### 5.3 エントリーカード：位置ゲージ（`gauge()`）と購入条件
- 位置ゲージ：−10〜+10%の目盛り（−10 / −5 / 0 / +5 / +10）、0〜+5%の帯、上にピボット（金額）、下に損切り例と買い上限（金額）、現在値の大きい点（状態色）。ラベルは上段58px・下段78pxに分け、重ならないようにする。
- 見出し：「エントリー位置　ピボット比 +0.03%　価格の位置のみ · 購入可否は右」。

### 5.4 価格チャート（`chart()`）
- 3段：価格（ローソク足、SMA50＝`accent` 1.5px、SMA150・SMA200＝細線）／RS線（対S&P500）／出来高（50日平均の点線、1.4倍以上を `--vol-hi`）。

### 5.6 業種ローテーション図（`rotation()`）
- 横：選んだ期間の相対指数（100＝SPYと同じ）。縦：直近21日の相対変化（%）。範囲は100・0%を中心に対称で、最大の振れ幅×1.2〜1.3。

## 6. 文言の原則
- 結論 → 行動 → 根拠の順。「〜です」を省いた体言止めと短い文。
- 「未確認」は「未達」と区別して書き、合格に数えない（指示書の共通ルール）。
- 英語の内部名（`cup_with_handle` 等）・英語のエラー文を画面に出さない。
- 金額は `$1,234.56`、比率は `+1.2%` / `−1.2%` / `±0.0%`、倍率は `1.27×`、日付は `2026年9月29日（火）` または `2026-09-29`（等幅）。
