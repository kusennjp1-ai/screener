## 3. タスク詳細

### P1　研究インデックスの軽量化とWorker化【P0・性能】

**証拠**
- CPU 4倍・390×844・通信除外で3回測定：
  - 候補表示まで 5,610 / 6,105 / 5,724 ms（前回監査 3,687 ms）。
  - 手法切替 867〜1,337 ms（前回 836 ms）。
  - 1倍の場合は、候補表示 1,386 ms・手法切替 199 ms。
- 研究インデックス `research-index-eb909f75….json`：5,901行、gzip後 1,848,585 B、展開後 17,488,569 B。
- 1行あたりのサイズ内訳：
  - `institutional_evidence` 810 B（30.7%）
  - `entry_evidence` 731 B（27.7%）
  - `technical_audit` 422 B（16.0%）

**対象ファイル**
`frontend/tools/export-research.mjs`、`frontend/src/static/pages/ResearchPage.jsx`、`researchEngine.js`、`portfolioPlan.js`、`components/CandidateBoard.jsx`、`useWorkbench.js`

**仕様**
1. 一覧用インデックスには、判定と一覧表示に必要な値だけを残す。
   - `institutional_evidence`：2期の報告運用会社数と増減、`status` のみ。出典URL・取得日時・制約文・`refresh` は銘柄別の詳細ファイルへ移す。
   - `entry_evidence`：決算予定日・`volumeRatio`・`shape.candidate`・カレンダーの有効期限のみ。説明文は詳細ファイルへ移す。
   - `technical_audit.values`：判定に使う数値だけを残す（close, sma50, sma150, sma200, sma200_21ago, aboveLow, belowHigh, volumeRatio, change, momentum）。
2. 数値は丸める（価格は小数2桁、%は2桁、比率は3桁）。
3. JSONの解析と行の前処理を Web Worker に移し、候補表示までメインスレッドを塞がない。
4. 手法ごとの並べ替えキーをエクスポート時に計算しておき、手法の切替は並べ替え済み配列の差し替えだけにする。
5. 既存の再現検証（全5,901銘柄の手法判定が正準ルールで再現されること）は維持する。

**受け入れ基準**
- 研究インデックスが gzip後 ≤ 1.0 MB、展開後 ≤ 8 MB。
- CPU 4倍：候補表示 ≤ 3.5 s（3回の中央値）、手法切替 ≤ 400 ms、読み込み中の最長タスク ≤ 200 ms。
- 既存の品質ゲート（一覧・詳細・チャート・CSVの一致）がすべて合格。

- 公開時に保存している判定の記録（workbench history）を使い、各分析日の「通過」銘柄について、分析日の終値から5 / 20 / 60営業日後の騰落率・同期間のSPY騰落率・期間中の最大下落率を集計する。
- 過去データの後付けはしない。表示には必ず「n（観測できた営業日数）」を付ける。
- 手法別の表に、中央値・勝率・n を出す。n < 20 の間は「参考値（標本不足）」と表示する。

**受け入れ基準**
- 固定データで計算の単体テストを書く。
- 最初の値は5営業日後に表示される。記録がない期間は空欄のままにする。

### F4　ウォッチ銘柄の状態変化通知【P3・機能】

**仕様**
- 日次公開の際に、ウォッチ銘柄の状態が「ピボット待ち→買いゾーン内」「買いゾーン内→超過」などに変わったら、アプリ内の通知一覧とPWAのローカル通知（許可制）で知らせる。
- 同じ変化を二重に通知しないよう、イベントIDで重複を防ぐ。
- 場中の通知は既存のFinnhub個人接続がある場合だけにし、鍵は保存しない（既存方針どおり）。

// node measure.mjs  （Chromium + axe-core 4.10 を使用）
import { chromium } from 'playwright';
import fs from 'node:fs';
const URL = 'https://kusennjp1-ai.github.io/screener/';

  const page = await ctx.newPage();

  const cache = new Map();
  await page.route('**/*', async r => { const u = r.request().url();
    if (cache.has(u)) return r.fulfill(cache.get(u));
    const res = await r.fetch(); const v = { status: res.status(), headers: res.headers(), body: await res.body() };
    cache.set(u, v); return r.fulfill(v); });
  await page.goto(URL); await page.waitForLoadState('networkidle');
  const cdp = await ctx.newCDPSession(page);
  await cdp.send('Emulation.setCPUThrottlingRate', { rate: 4 });
  const t0 = Date.now(); await page.goto(URL);
  await page.waitForFunction(() => /条件通過\s*[1-9]/.test(document.querySelector('.research-summary')?.innerText || ''));
  console.log(vp.width, 'ready ms', Date.now() - t0);

    chrome: [...document.querySelectorAll('body *')].filter(e => ['fixed','sticky'].includes(getComputedStyle(e).position))
      .reduce((s, e) => s + e.getBoundingClientRect().height, 0),
    smallTargets: [...document.querySelectorAll('button,a,[role=button],summary,select,input')]
      .filter(e => { const b = e.getBoundingClientRect(); return b.width && b.height && (b.height < (innerWidth < 768 ? 44 : 24) || b.width < (innerWidth < 768 ? 44 : 24)) && !e.closest('p'); }).length,
  })));
  // アクセシビリティ
  await page.evaluate(axe);
  console.log(await page.evaluate(async () => (await axe.run(document, { runOnly: ['wcag2a','wcag2aa'] })).violations.map(v => [v.id, v.nodes.length])));
  await page.unrouteAll({ behavior: 'ignoreErrors' }); await ctx.close();
}
await browser.close();
