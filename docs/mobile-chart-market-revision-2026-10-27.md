## Public institutional-data decision

The user explicitly selected public information. Existing SEC archive aggregation provides positive reporting-manager CIK counts for two consecutive report quarters, with filing date ranges and a public cutoff. It does not contain daily purchases, execution prices, share purchase amounts or a daily rank series. The implementation must not interpolate a filing range into daily transactions.

Cross-stock comparisons use the same pair of report quarters and cutoff. Missing, stale, mismatched-symbol, future-publication and malformed evidence remain excluded rather than zero. Existing aggregation distinguishes restatements and new-holdings amendments, deduplicates reporting managers and omits ambiguous stock classes. The count metric does not turn stock-split share changes into purchases.

Primary references: [SEC Form 13F](https://www.sec.gov/files/form13f.pdf), [Investor.gov 13F explanation](https://www.investor.gov/introduction-investing/investing-basics/glossary/form-13f-reports-filed-institutional-investment). The [SEC-hosted NYSE notice](https://www.sec.gov/Archives/edgar/data/876661/000087666126000397/ruleprovisionnotice.htm) documents CCL's 2026-05-07 transition from CUSIP 143658300 to G2004J103. Cross-quarter comparisons spanning that date become unknown in the shared sponsorship rule and are retained as raw observations outside the ranking. Counts are not summed across identifiers because manager overlap is unknown.
