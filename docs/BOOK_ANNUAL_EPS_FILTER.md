# 年次EPSの任意AND絞り込み（レビュー候補）

研究画面に「年次EPS：各年増益＋3年CAGR25%以上（書籍付録Aの一部）」を追加。初期状態は無効です。

## 範囲と原典

- 『オニールの相場師養成講座』提供された歴史的日本語版、付録A 表A.1 の年次EPS抜粋。PDF 197、説明 PDF 202–203（提供PDFの1始まり位置）。
- 3回すべての年次増益と、3年CAGRが25%以上の数値比較です。
- 実装入力は報告希薄化EPSで、調整後の継続事業EPSを独立に確定したものではありません。利益の調整、株式単位、分割、ADR等は手動確認が必要です。
- AAIIの機械的実装全体、歴史的主本文、付録B、完全なCAN SLIMを認定しません。TTM、予想利益、EPS加速、IPO代替等はこの追加条件では未評価です。
- 米国株の研究画面のみ。従来の `/daily`、`/scan` の絞り込み・ルールには追加していません。

## 実際の動作

既存の手法、検索、流動性、業種、ウォッチ、検証状況、全条件通過／あと1条件を先に適用。その対象内の「数値充足・未充足・未確認・対象外」件数を表示します。追加条件が有効なら、数値充足のみを残し、元の順位を維持します。

基本手法の判定、スコア、通過数、購入条件、配分、リスクは変更しません。5番目の手法ではありません。上部の概要・配分・日次変化は従来の範囲であることを有効バッジに明示します。

例：EPS `1 → 1.2 → 1.6 → 2` のCAGRは約25.9921%で、この追加条件は充足します。オニールの既存「各年25%以上」条件は最初の年が20%なので未達のままです。既存のオニール「全条件通過のみ」と組み合わせても通過に変更しません。

一覧、比較チャート、詳細選択、拡大チャートの移動先、CSVは同じ絞り込み結果を使用。追加条件は有効バッジを常時表示し、詳細と書籍カードは同じ純粋関数から再計算します。URLの `annualEps=1` のみ有効と認識し、戻る／進むとモバイル表示で復元します。結果から除かれた選択・拡大チャートは保持しません。

## 証拠・不明・期限

- 既存の `currentFinancialHistory()` を通した、日付付き連続4年度と3つの比較だけを使用。古い成長率スカラー、キャッシュの合格フラグ、欠損の補間は使用しません。
- CAGRは4つすべてのEPSが正で比較可能な場合だけ計算。未丸めの終点／起点比を `1.25^3` と比較します。
- 一部欠損でも、証拠付きの年次減益・横ばいがあれば集約は未充足。CAGR等の不明成分も併記します。不明を合格にしません。
- 基準日、銘柄、観測スコープ、日足監査の銘柄が矛盾する場合は未確認。市場はこの最初の実装では明示的にUS限定。年次履歴に市場が明記されていればUSと一致が必要です。
- 異なる通貨・基準・株式単位等の年次セルのメタデータを圧縮で消しません。拒否専用マーカーは `undefined` のJSON脱落でも拒否を維持。マーカーの不在だけで出典の正当性を認定しません。
- 証明済みファンドは対象外。銘柄同一性の衝突は未確認。
- 取得後72時間は既存仕様どおり境界を含め、+1msで失効。既存入力契約の最大5秒の時計ずれ許容は維持しています。
- 価格基準日はNew York暦日で4日目の午前0時に失効。DSTと長い休日を含めて計算し、Workerの最短失効時刻に組み込みます。
- 取得時点での比較です。価格基準日に公表済みだった履歴の証明ではありません。報告公表日時がないところに公表済みの主張を追加しません。

Workerは評価ごとに追加条件を再計算し、行所有関係・評価時刻・世代・評価番号に結び付いた状態インデックスを150件以下のパケットで配信します。全体インデックスを最終パケットへ詰め込みません。失効中は旧評価を表示せず、旧世代の遅い再計算で復活させません。

## CSVと公開品質チェック

追加条件を無効にしたCSVの既存列・内容は維持。有効時は保存クリック時の時刻で再計算して失効済み行を除外し、条件ID／版、原典の範囲、集約・成分状態、4つのEPSと年度、各年の成長率、CAGR、通貨・基準・提供元、取得・失効・評価時刻、存在する実際の受領証参照、手動確認要／手法全体未評価を追加します。

公開品質チェックは正規詳細、圧縮リスト、JSON符号化・復号、Workerパケット、詳細統合、CSVの年次数値比較を照合します。基礎判定・順位・配分の従来照合も維持します。

## 検証の限界

実行結果は対象commitのCIログ・テスト証跡で確認します。`book-annual-filter.spec.js` は合成入力を使う実ブラウザー用回帰であり、実行前に画面・モバイル・アクセシビリティの合格は認定しません。jsdomや静的ビルドだけでは実ブラウザーの検証になりません。ローカルの配信データがない場合、静的ビルド成功は現在の実データ再生成や本番配信の成功を意味しません。
