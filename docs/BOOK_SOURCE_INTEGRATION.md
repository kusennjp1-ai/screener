# 4冊の書籍条件を使った比較表示

日付：2026-10-10。レビュー用の実装候補です。この変更自体はサイト配信や注文を行いません。

年次EPSの任意AND絞り込みを含みます。追加条件の動作・証拠・期限・CSVの仕様は [BOOK_ANNUAL_EPS_FILTER.md](BOOK_ANNUAL_EPS_FILTER.md) を参照してください。

## 何を反映したか

実際の静的アプリ経路で、銘柄詳細の「書籍検証」に「4冊の条件と現行判定」を追加しました。説明文だけではなく、現在の検証済み入力から下記の比較を再計算します。

| 対象 | 原典と反映内容 | 現行の選定・購入条件との関係 |
| --- | --- | --- |
| 『株式トレード 基本と原則』 | PDF 221–222 の安値比25%以上と、PDF 245 の約2〜3%追随目安 | minervini2 の25%／3%設定は維持。「出典未確認」という古い説明を訂正。3%超の価格位置には、この書籍名付きの注意も表示 |
| 『ミネルヴィニの成長株投資法』 | PDF 151–152 の安値比30%以上、PDF 372–383 の約2〜3%追随目安 | minervini の30%／5%設定は維持。25〜29.99%では両書の低値条件の違いを数値で表示 |
| 『成長株投資の神 / Momentum Masters』 | PDF 145–144・問4.17の4人の出来高条件を分けて表示 | Minervini は50日平均超、Ryan は1.25倍との参考比較。Ryan の同回答では期間が未指定なので、50日窓をアプリの選択と明記。Zanger の20日比は欠測として未確認、Ritchie II は固定閾値なしの個別確認 |
| 『オニールの相場師養成講座』売上 | PDF 66 の「最近の1期以上が前年比25%以上、または直近3四半期の伸び率加速」 | 証明付きの最新1期の25%枝だけ比較。25%未満は代替経路が未確認のため、書籍全体の未充足にはしない。現行の単期25%ゲートは維持 |
| 同・年次EPS | PDF 197・202–203・212の「各年増益＋3年複利成長25%以上」の2条件 | 連続4期から比較。現行アプリの「各年25%以上」との同じ4期による閾値比較を併記。実際の選定結果は部分的な既知の未達も扱うため、「判定根拠」タブと区別 |

全12カードは、必須条件、好ましい特徴、著者個人の最低目安、裁量、限定例外、アプリ独自制約を区別します。コード33は4四半期で3回の改善を測る加点材料、パワープレーは限定例外として説明します。検出フラグや例外だけで通常の業績条件を通過させません。

原典のページは、今回提供されたPDFの1始まりの位置です。以前のKindle表示位置からの換算を主張していません。印刷ページ番号は不明です。『相場師養成講座』の説明は2004年版の歴史的な方法で、現行IBDの仕様認定ではありません。主本文、付録AのAAII機械的実装、付録Bの閾値の違いを残します。

## 数値と出典の結び付け

- 低値比較：同一銘柄・基準日の検証済み日足から、終値÷直近252営業日の日中安値−1。252営業日はアプリの52週近似です。
- 出来高比較：当日出来高÷当日を除く直前50営業日の平均。当日除外はアプリの定義です。正しい上放れ、場中の出来高確認完了、約定の証明ではありません。
- 売上：現在有効な financial-current 証明のみ使用。比較する2期、提供元、取得時刻、有効期限を表示します。生の単期スカラーや古いスコアに戻りません。
- 年次EPS：既存の出典・72時間鮮度・期間契約に加え、曖昧さのない3つの annualComparisons と4つの正のEPSが必要。通貨やEPS基準の不一致、欠損年、ゼロ／赤字基準、銘柄・市場・観測スコープの不整合は未確認です。
- 未来・古い日足や基準日不一致、銘柄・市場名の欠落は数値通過にしません。比較表示の鮮度制約は実際の選定とは別で、現在の最終取引日を自動証明するものではありません。
- 検証済みファンドは対象外、同一性の不一致は未確認。匿名・別銘柄の証明を転用しません。

## 具体例

- 52週安値比27%：『基本と原則』の25%比較は充足、『成長株投資法』の30%比較は未充足。
- 直前50日出来高比1.30倍：Minerviniの平均超と、アプリが50日窓を選んだRyanの1.25倍比較は充足。共通購入モデルの1.4倍条件は未充足。Zangerの20日条件は未確認。
- 年次EPS 1.00 → 1.20 → 1.60 → 2.00：すべて増益、3年CAGRは約25.99%。この年次2条件は充足しても、アプリの各年25%以上では20%の年が未達。
- 最新売上前年比20%、過去の成長率が不足：現行の単期25%ゲートは未達。書籍の代替条件全体は未確認。

## 維持した境界

基本4手法の選定判定・順位、共通購入条件、RSの証拠、財務証明、IPO／HTF判定、口座リスク0.25%／0.5%などの保守的な設定は維持します。追加の年次条件が無効なら従来のCSVを維持し、有効なら基本手法の結果内で一覧・CSVを絞り込みます。コード33の表示用AND集約は、既知の未達が不明成分で隠れないよう修正し、不明成分自体は不明のまま残します。損切りは約定保証ではありません。書籍比較を購入許可として扱いません。

この版は4冊の全条件を実装したものではありません。既存の詳細業績・パターン・リスクの機能がすべての原典条件と一致するとも認定しません。今回のカードから自動注文や公開更新は行いません。

## 次に独立して実装できる範囲

現行の厳格なオニール方式を上書きせず、明示的に選べる書籍プロファイルを別途設計できます。主本文とAAII／付録Bを混ぜた一つの「正解」にせず、まず売上の代替条件だけを独立した機能として実装するのが小さい変更です。

必要な契約：直近3期それぞれの比較可能な売上前年比、対応する原売上と前年同期、期末・期間長・通貨・取得時点・利用可能期限。単なる3個の数値や、日付のない acceleration=true は証拠にしません。

次の受入例：
1. 5% → 10% → 20% は加速枝が充足、現行の単期25%ゲートは未達。
2. −5% → 10% → 30% は書籍の例に対応。前期からの売上額増加ではなく、各期の前年比の増加を比較。
3. 30% → 25% → 26% は加速枝が未充足でも、25%以上の枝が充足。
4. 最新20%＋過去欠損は未確認。既知の一枝が充足すれば限定したORは充足、両枝が証拠付きで未充足の場合だけその限定モデルを未充足とします。原典の「最近の1期以上」の期間幅は固定されていないため、最新1期モデルの未達で原典全体の未達を確定しません。
5. 期限切れ、別銘柄、期間長不一致、通貨変更、非正の基準売上、将来の公表値は未確認。
6. 実装済みの年次追加条件では、途中減益をCAGRで隠しません。AAII用のTTM追加条件やIPO代替は、必要入力なしに自動通過にしません。

## 検証

- 単体・Reactコンポーネント試験は、数値境界、既知の未達と不明、失効、通貨／EPS基準、観測同一性、圧縮・Worker・CSV整合、初期無効とURL復元を対象にします。
- 実ブラウザー用の `frontend/tests/static/book-source-comparison.spec.js` と `book-annual-filter.spec.js` は、明示した合成入力で書籍カード、レスポンシブ表示、絞り込み、CSV、戻る／進むを確認します。合成入力を本番資料として公開しません。
- 実行済みの結果は、この変更に対応するCIの `Static Browser Regression` と添付テスト証跡で確認してください。試験の追加・列挙、コンパイル成功、jsdom試験だけを実ブラウザー合格と扱いません。
- 書籍の全文や全条件の詳細な読書資料は同梱せず、条件の短い言い換えと書誌・提供PDF位置だけを使います。

### 現在のデータだけで実装できる部分／できない部分

- 今回の年次追加条件は、出典契約に通った annualComparisons を使用します。既知の増益失敗と欠損を論理ANDで区別し、CAGRに必要な連続4期を捏造しません。
- financial_current の sales_growth_yy は最新1期の前年比を証明します。periods_used の日付列から過去2期の売上成長率を復元することはできません。
- book_financials に期間長・提出日を確認できる売上系列がある銘柄はありますが、既存の salesAcceleration はコード33用の「4四半期・3回改善」です。オニールの「3四半期・2回改善」とは別の判定です。
- よって全ORを選定に使うには、過去2期も含めた3個の時点付き成長率証明、または3期と前年同期3期の原売上を同一銘柄・基準日・通貨・期間・出典・期限に結び付ける契約が必要です。現行のコード33表示用Booleanだけを流用しません。
