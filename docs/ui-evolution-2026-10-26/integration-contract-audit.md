# Compact UI integration and anti-pattern audit

This review concerns the local implementation and existing verification contracts. It does not claim a published build, physical-device validation, or final design approval.

## Correctness and interaction review

- Fixed a real VCP state defect: selecting C1 opened its chart range, but returning to the lab remounted its local button state. The chart now supplies its selected leg to the evidence control. A regression checks VCP → chart → VCP selection/range retention and reset on a different chart identity.
- Full verification caught the RS-history attachment crossing the source-bound financial projection boundary. The independent RS field is now attached after financial projection/cleanup, preserving the original projection byte-for-byte where required. All 51 financial carry tests passed after this placement correction, including stale-source/reporting-period reasons, source clocks, inherited ownership, fund exclusions and repeated serialization; no pinned fixture or comparison was changed.
- A short, unavailable-chart screen could not scroll its initial 12px top gap down to the existing 8px keyboard-focus clearance. Detail-only top padding is now 8px, matching the established scroll padding. All seven safe-inset/viewport cases passed, with the original exact clearance and nine-point back-button hit tests unchanged.
- Browser weekly-chart verification exposed numeric moving-average, preceding-volume and price-guide legends missing from the compact chart view. The same values are now retained inside its existing initially closed chart-help disclosure; desktop legends stay in their original location. Tests require the actual daily/weekly numbers, independent grouped OHLCV, the initial 252-bar range and count, and the absence of duplicate legend groups. The operation selector now distinguishes the exact “操作” control from the longer help title.
- Existing browser suites now explicitly select the mobile section before checking its values. They continue to check annual EPS edge cases, financial provenance, unknown/failed states, dates, exact labels, keyboard focus, numeric chart values, overflow, 44px targets, and accessibility. No test was skipped and no acceptance threshold was relaxed.
- The six-section navigation uses native buttons, tab roles, roving focus, Arrow/Home/End keys, and existing stable IDs. The extra global navigation is absent only inside mobile stock detail; the persistent candidate-list action restores it. The chart is hidden to retain its range, while inactive evidence content is not appended to the page.
- The companion derives its expression from existing readiness, has a visible text explanation and native closed disclosure, respects exclusions/unknowns, and disables its single entrance animation under reduced motion. It does not generate a new investment signal.
- RS rating history remains distinct from the price-relative RS line. Source and missing-data validation are covered separately by the domain review and producer tests; the UI review does not certify externally supplied historical data merely from its appearance.

## Versioned capture contract

The new `leader-tabbed-detail-v2` capture contract measures the actual chart tab and then the actual purchase-conditions tab for the same displayed instrument/date, before returning to the chart. It requires six reachable 44px section buttons, exactly one selected section, seven original state values, five original gates, the original price-pane visibility budget, and actual fixed-chrome hit tests. Financial captures likewise prove which section is selected. Report/observation version mismatches are rejected to prevent downgrading a v2 proof to v1 requirements.

Existing `leader-svg-detail-v1` evidence remains supported with its original requirements. Numeric, source, screenshot binding, geometry and functional checks were not removed. Real public EPSN data rendered by local source passed v2 chart, selection and purchase geometry checks; the chart observation retained RS 82 and volume ratio 0.54 from the visible conditions section. This was a read-only local preview, not public-deployment evidence.
