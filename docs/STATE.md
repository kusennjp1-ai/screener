## 本セッションで確定した「計測系の誤り」（戦略より先に疑うこと）

1. **`--pit-universe` が `--funnel product` の下で無効化されていた**。バンド判定表を凍結リストからしか作らず、後期上場銘柄は `.get(s, False)` で全て脱落。実行は「点時点に見えて凍結として振る舞う」＝**正しいと自称する誤った数字**。修正済み。
2. **フラグが出力に記録されていなかった**（progressive_risk / selective_pressure / breadth_confirm）。どの設定で測ったかを成果物から判定できなかった。記録するよう修正＋出荷版と一致しない実行には警告を自動付与。
3. **製品が同じ銘柄に2種類の建玉サイズを出していた**。スキャナ経路は 1.25%→2.5%、スマホ書き出しは常に 1.25%。公開バンドル26箇所すべて 1.25 ＝ **スケールした値は誰にも表示されない死んだ分岐**。統一済み＋再分岐を検出するテスト追加。
4. **`risk.py` の「両窓改善・ドローダウン不変」は誤り**。撤回済み（下記）。
5. **VCP判定に使っていた pp-gap 指標は緩和を報酬する**（両率が上がれば gap は増える）。今後は lift で判定すること。

## C103 の結論（このサイクルで確定した否定的結果）

**再現率はリターンの梃子ではなかった。** ベース固定型検出（C102・908基準では
再現率36.1→40.3%かつ精度も向上）を売買経路に入れると**両窓とも悪化**:
5年 CAGR 10.7→**8.0**（最大DD −15.8→−20.9）、9年 11.5→**8.2**（−18.4→−21.8）。
増えたトレード(+12/+46)が損を出す。∴ 検出器は**表示と並び順**では採用、
**売買経路では無効**（`--base-anchored` は既定オフのまま）。

**強さへの利確も両窓で棄却**: 全部利確 5年12.1/9年**9.1**、半分利確 5年9.4/9年**7.8**。
5年窓だけなら全部利確は魅力的に見える（CAGR+1.4pp・Sortino1.33）＝**片窓判定は必ず誤る**。

**残っている道**: リスク%↑（棄却）・利確（棄却）・現金規律解除（棄却）・検出率↑（棄却）・
模擬の上限（存在しない）。**リターン式の全項目を一度ずつ潰した**。次に試すなら、
まだ触っていない (a) 保有期間/決済ルール、(b) ファンダ条件（point-in-time 未取得）、
(c) ユニバース（現在 ≥$2B の1,570銘柄のみ＝小型の右テールが不在）。

## シミュレーションの上限（C103 監査・実測で決着）

**模擬のせいで届かない、という言い訳は使えない。** 期待値 +0.1R あたり CAGR +2.7pp(5y)/+3.0pp(9y) で**線形**。完璧な選択器なら年約70%。構造的上限は存在しない。
- 疑っていた3件は**実測で否定**: 10枠は 1,246日中**0日**しか埋まらない（平均同時保有4.6件）／ストップ後の再エントリーは**完全に可能**／決済の翌日始値ラグは ±0.1pp。
- 約定モデルはピボットより平均 **+2.24%** 高く入る（年率換算 約7.9pp）が**回収不能**: 距離とリターンの相関 −0.062、**ピボットに最も近いレーン（armed）は両窓とも損失**（−0.18R/−0.06R）で、利益は全て +2.6% 上で追いかけたレーンから出ている。翌日始値は同日の確認フィルタとして機能しており、7.9pp はその対価。
- **実現リスクは 1.25% ではなく 0.874%**（エクスポージャー上限が建玉を切り詰める。158件中97件が1.20%未満）。正しい式 31.8 × 0.398 × 0.874% = 11.1% ≒ 実測 10.7%。**説明のつかない漏れは無い**。
- **投下資本あたりの収益は年17.7%**（SPY は100%投資で12.4%）。選択は機能している。制約は資金の1/3が現金であること。
