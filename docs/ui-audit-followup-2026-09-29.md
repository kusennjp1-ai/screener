# UI監査再検証（2026-09-29）

Claude監査の一部は旧公開データに対するもの。前回変更で修復後セットアップ再計算、機関数の参考資料、詳細スキャンの一覧/詳細分割は公開済み。今回の変更は判定条件を変更せず、残る表示・性能・アクセシビリティの不具合を修正する。

## 修正
- 検証済みの簡易チャートにも、日足終値と同日のSPY終値からRS線を出力。NDSN/IRDM/EBAYは各309点。RS順位とRS線の意味は区別。
- 日次判断をコンパクトにし、候補一覧を状態・ピボット比・RS・出来高比へ変更。50件ごとの描画と固定表示。全件の検索・並べ替えを維持。
- 検索入力を独立させ150ms待って絞り込み。銘柄詳細をメモ化。15秒の時刻確認は鮮度・市場営業日・購入条件の状態変化があるときだけ全画面へ通知。
- 判定サマリーを配列へ圧縮。日足/再計算ハッシュは銘柄詳細に保持しホームの要約から除外。全5898銘柄の判定を元のルールエンジンで再照合。
- スマホの候補移動は検索へのフォーカスを廃止。候補一覧/銘柄分析を下部固定。テーマボタン44px、詳細スキャンを銘柄カードに対応、補助フィルターは開く形式。
- 移動平均乖離は株価÷移動平均−1。スマホでは平均線の詳細を開く方式。リサイズ後も初期63営業日を維持。
- ライトモード見出し・市場環境の色とアクセシビリティ属性を修正。

- NDSN/IRDM/EBAYは309点、AMD/TSM/JPM/KLACは501点のRS線を出力。
- gzipの研究索引: 2,631,871 → 1,959,723 bytes（25.5%減）。展開後23,594,870 → 17,424,771 bytes（26.2%減）。詳細の証跡は遅延取得で保存。
